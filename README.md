# Norrgläntan

En responsiv startsida för den fiktiva naturdestinationen "Norrgläntan". Byggd enligt instruktioner i Laboration 3 
för webbutvecklingsprogrammets kurs *"Introduktion till webbutveckling med HTML, CSS och Javascript - dt224g".*

## Innehåll

- **Header/navigation** – logotyp, webbplatsnamn och länkarna Upptäck, Aktiviteter, Boende, Hitta hit.
- **Hero** – helbredds bild, rubrik, ingress och en call-to-action-knapp.
- **Introduktion** – rubrik och brödtext om Norrgläntan.
- **Aktiviteter** – tre kort, "puffar", (Vandra, Paddla, Upptäck) med bild och text vardera.
- **Avslutande sektion** – rubrik, text och knapp ("Planera ditt besök").
- **Footer** – logotyp, citat, kontaktuppgifter och länkar till sidans sektioner.

## Tekniker

- **Semantisk HTML**
- **CSS**
- **Google Fonts** 

## Responsivitet

Sidan är skriven mobile first med en brytpunkt vid **768px**.
 
- **Mobil (< 768px):** navigationen visas vertikalt, hero-bilden ligger över texten, aktivitetskorten staplas under varandra.
- **Större skärm (≥ 768px):** navigationen visas horisontellt, hero-texten läggs ovanpå bilden med en mörk toning för läsbarhet, aktivitetskorten visas tre i rad, och footern delas upp i tre kolumner.
